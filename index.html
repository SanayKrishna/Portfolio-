02Selected work
  1. 01
    MITRE ATT&CK Cloud Detection Engine ATT&CK-MAPPED

    It reads AWS CloudTrail logs, from files or live through Boto3, and flags attacker activity like logging being switched off, extra access keys added to accounts, or data moved to an outside AWS account. Every alert is labelled with its MITRE ATT&CK technique, taken from MITRE's official dataset.

    • 39 rules covering 20 techniques; each rule is a small data object, so adding a detection never touches the engine
    • Rules match real CloudTrail logs, not the spec: console logins are logged under signin.amazonaws.com
    • Coverage page shows which cloud techniques still have no rule; 33 tests run against the real MITRE data
    Python · FastAPI · Pydantic v2 · Boto3 · MITRE STIX · pytest
    GitHub ↗
  2. 02
    CloudScanner AWS-NATIVE

    An S3 security monitor. It scans every bucket in an AWS account for public access, loose ACLs or policies, and cross-account access, then watches live S3 activity for risky changes.

    • Each finding rated Low to Critical against the CIS AWS Foundations Benchmark
    • CloudTrail → EventBridge → Lambda pipeline catches bucket policy changes and deletions
    • SNS alert shows who made the change, from which IP, and on which bucket
    Python · FastAPI · Jinja2 · Boto3 · AWS Lambda · CloudTrail · EventBridge · SNS · Terraform
    GitHub ↗
  3. 03
    AI-Powered SOAR Engine SOC TRIAGE

    An alert-triage prototype. A Random Forest model trained on synthetic alerts scores each incoming alert from 1 to 100, and the score decides the playbook.

    • Playbooks: open a ticket, notify the team, or isolate the endpoint (simulated)
    • Every alert and action logged to SQLite as an audit trail
    • Flask and Chart.js dashboard shows the live queue and risk trends
    Python · Flask · Scikit-learn · Pandas · Chart.js · SQLite · Vercel
